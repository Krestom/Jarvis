## Операционка (как что делать)

- **Деплой на прод**: `ssh jarvis-srv` → `cd /opt/jarvis && git pull --ff-only &&
  docker compose up -d --build`; миграции применяет сервис `app` (entrypoint).
  После: `docker compose ps` и `docker compose logs --tail=30 app`.
- **Читать состояние/бэклог**: `docker compose ps`/`logs`;
  `docker compose exec -T postgres psql -U jarvis -d jarvis` (SELECT);
  владельцу — `/diagnostics` и `/export_issues` в боте. Статусы записей backlog
  менять через бота или код приложения (`ImprovementRepository`), не сырым SQL.
- **Бэкапы**: cron 04:00 (`/home/deploy/jarvis-backups`); проверка —
  `scripts/verify_backup.sh <каталог>`; тестовое восстановление — `scripts/restore.sh`
  (изолированный проект, прод не трогает).
- **Выгрузки с сервера скриптом**: вложенный python через ssh на Windows может
  побить кириллицу — кодировать вывод в base64 на удалённой стороне и декодировать
  локально.
- **Ошибки бота**: автоматически попадают в `/diagnostics` (backlog) и сообщением
  владельцу в чат; correlation id связывает запись с `docker compose logs app`.

## Навигация in-place: меню, карточки, пикеры, комментарии (17.10, НЕ задеплоено)

Продолжение «одно сообщение на экран» — теперь правится вся навигация:

- **Меню**: «Задачи/Знания/Документы/Проекты/Настройки/Секреты/Диагностика» из
  главного меню правят сообщение меню; «🏠 В меню», «📋 К спискам», «К списку» —
  возврат правкой (`send_settings(edit=)`, `menu_*`).
- **Карточки** (задача/заметка/документ) открываются правкой сообщения-источника
  (список/поиск/пикер) и сами — одно сообщение (текст + «Действия:» + кнопки).
- **Комментарии**: карточка ↔ список комментариев правкой («⬅️ К задаче»);
  вынесено в `open_entity.render_comments_view` (используется и в подтверждениях).
- **Пикеры**: «🗂 Группа» (задача) и «🗂 Категория» (документ) правят карточку,
  «⬅️ Назад» возвращает.
- **Полный текст заметки**: правка карточки; кнопка-переключатель «📕 Свернуть».
- **«🔎 Похожие»**: результаты правят карточку + «⬅️ К записи».
- **Поиск**: открытие хита правит результаты + «⬅️ К результатам» (номер
  страницы из колбэка, новая action `page_go`).
- **Секреты**: список и листание страниц правкой.
- **Подтверждения**: после «Подтвердить» превью превращается в свежую карточку
  (задача/комментарии/заметка/документ); удаления и категории/проекты — «✅ …» +
  кнопка к нужному списку (`ConfirmResult` несёт `operation_type`/`entity_id`).

Остаются отдельными сообщениями (по природе диалога): ввод текста (срок,
название, комментарий), превью подтверждений, файлы и ответы агента.

Живая проверка (Luna): список→карточка→группа→назад→комментарии→назад→меню задач→
главное меню→документы→карточка→категория→назад — все переходы правят одно
сообщение (0 новых). Тесты: 367 passed (e2e обновлены: навигация правит, а не
шлёт; идемпотентность подтверждений — в integration), ruff чист. Тест-бот
перезапущен 23:53.
