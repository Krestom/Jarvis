## Известные ограничения (осознанные, не баги)

- Очередь/отмена агента — процесс-local (развёртывание однопроцессное).
- Веб-поиск: провайдер не подключён (доступны `none` и `fake`).
- Файлы экспортов в контейнере эфемерны (уходят в Telegram; том не заведён).
- `scripts/restore.sh` восстанавливает только в тестовое окружение.
- merge дублей backlog — только через сервис (без UI в боте).
- Напоминания и утренняя сводка работают, пока процесс бота жив; адресат — первый
  пользователь из allow-list; окно сводки — 30 минут после `NOTIFY_DIGEST_TIME`.
- Агент не создаёт секреты и документы (только знания — через подтверждение).
